# 💰 Expense Tracker MCP Server

An asynchronous **Model Context Protocol (MCP)** server built with **FastMCP**, **Supabase (PostgreSQL)**, and **WorkOS AuthKit (OAuth 2.1)**. This server enables LLMs (such as Claude) to perform natural-language expense tracking, structured querying, financial summarization, and granular record modifications with strict multi-tenant isolation.

---

## 🚀 Features

- **🗣️ Conversational Expense Tracking**: Seamlessly log expenses directly through natural language conversations with an LLM.
- **🔍 Filtered Search & Retrieval**: Query expenses filtered by date range (inclusive), category, or exact amount.
- **📊 Financial Analytics & Summarization**: Compute category-wise spending totals across arbitrary date ranges using dynamic aggregation.
- **✏️ Granular Expense Modifications**: Edit individual fields (amount, date, category, note) or delete records with zero prompt ambiguity.
- **🔒 Multi-Tenant Data Isolation**: Uses WorkOS JWT claims (`sub`) mapped to internal user IDs in Supabase to enforce strict per-user boundaries.
- **🛡️ Type-Safe Validation**: Powered by Pydantic models and a 20-category enumeration (`Category`) to eliminate LLM hallucinations during tool execution.
- **⚡ Asynchronous & High Performance**: Built on non-blocking async PostgreSQL sessions with graceful lifespan connection management.

## 🗄️ Database Setup (Supabase)

Before running the server, configure the following tables in your Supabase SQL Editor:

```sql
-- 1. Enable UUID extension (if not already enabled)
CREATE EXTENSION IF NOT EXISTS "uuid-ossp";

-- 2. Create Users Table
CREATE TABLE IF NOT EXISTS users (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    workos_user_id TEXT UNIQUE NOT NULL,
    created_at TIMESTAMPTZ DEFAULT NOW()
);

-- 3. Create Expenses Table
CREATE TABLE IF NOT EXISTS expenses (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    user_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    date TEXT NOT NULL,          -- Format: YYYY-MM-DD
    amount NUMERIC NOT NULL,     -- Expense amount
    category TEXT NOT NULL,      -- Matching Category Enum
    note TEXT NOT NULL,          -- Description
    created_at TIMESTAMPTZ DEFAULT NOW()
);

-- 4. Create Indexes for High-Performance Querying
CREATE INDEX IF NOT EXISTS idx_expenses_user_id ON expenses(user_id);
CREATE INDEX IF NOT EXISTS idx_expenses_user_date ON expenses(user_id, date);
CREATE INDEX IF NOT EXISTS idx_expenses_user_category ON expenses(user_id, category);
```

## ⚙️ Environment Variables

Create a `.env` file in the root directory:

```env
# Supabase Configuration
SUPABASE_URL=https://your-supabase-project.supabase.co
SUPABASE_KEY=your-supabase-service-role-or-anon-key

# WorkOS AuthKit Configuration
AUTHKIT_DOMAIN=https://your-authkit-domain.workos.com
BASE_URL=http://localhost:8000
```

| Variable | Description |
|---|---|
| `SUPABASE_URL` | Your Supabase project URL (`https://<project-ref>.supabase.co`). |
| `SUPABASE_KEY` | Your Supabase API key (use service-role or anon key with proper RLS). |
| `AUTHKIT_DOMAIN` | Your WorkOS AuthKit domain (used for JWKS fetching and issuer verification). |
| `BASE_URL` | Public base URL of your running server (used for audience validation: `{BASE_URL}/mcp`). |

## 📦 Installation & Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/sparshgoyal199/expense-tracker-mcp-server.git
   cd expense-tracker-mcp-server
   ```

2. **Install `uv` (if not installed)**:
   ```bash
   # Windows (PowerShell)
   powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"

   # macOS/Linux
   curl -LsSf https://astral.sh/uv/install.sh | sh
   ```

3. **Install dependencies**:
   ```bash
   uv sync
   ```

4. **Run the server**:
   ```bash
   uv run python main.py
   ```
   The MCP server will start listening on `http://0.0.0.0:8000`.

## 🤖 MCP Tools Reference

The server exposes the following 8 tools to connected MCP clients:

| Tool Name | Parameters | Description |
|---|---|---|
| `add_expense` | `date` (YYYY-MM-DD), `amount` (float), `category` (enum), `note` (str) | Records a new expense entry linked to the authenticated user. |
| `list_expenses` | `start_date` (opt), `end_date` (opt), `category` (opt), `amount` (opt) | Retrieves user expenses with flexible date ranges and field filters. |
| `summarize` | `start_date` (str), `end_date` (str), `category` (opt) | Aggregates and returns spending totals grouped by category. |
| `edit_expense_amount` | `id` (int), `amount` (float) | Updates the financial amount of an existing expense record. |
| `edit_expense_date` | `id` (int), `new_date` (str) | Updates the date of an existing expense record. |
| `edit_expense_category` | `id` (int), `new_category` (enum) | Updates the category classification of an expense. |
| `edit_expense_note` | `id` (int), `new_note` (str) | Updates the note/memo of an expense record. |
| `delete_expense` | `id` (int) | Permanently deletes an expense record by its ID. |

### Supported Categories
`food`, `transport`, `housing`, `utilities`, `health`, `education`, `family_kids`, `entertainment`, `shopping`, `subscriptions`, `personal_care`, `gifts_donations`, `finance_fees`, `business`, `travel`, `home`, `pet`, `taxes`, `investments`, `misc`.

## 🔌 Connecting with Claude

### Local Claude Desktop Setup
Add the server configuration to your `claude_desktop_config.json`:

```json
{
  "mcpServers": {
    "ExpenseTracker": {
      "command": "uv",
      "args": [
        "--directory",
        "/absolute/path/to/expense-tracker-mcp-server",
        "run",
        "python",
        "main.py"
      ],
      "env": {
        "SUPABASE_URL": "https://your-supabase-project.supabase.co",
        "SUPABASE_KEY": "your-supabase-key",
        "AUTHKIT_DOMAIN": "https://your-authkit-domain.workos.com",
        "BASE_URL": "http://localhost:8000"
      }
    }
  }
}
```

### Remote / Cloud Integration (e.g. Render)
When hosted remotely over HTTP / Server-Sent Events (SSE):
1. Deploy the service to Render (or any cloud provider).
2. Point your MCP client to your remote endpoint: `https://<your-render-domain>/mcp`.
3. Provide the Bearer token generated by WorkOS AuthKit in the `Authorization` header.
